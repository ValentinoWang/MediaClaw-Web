# MediaClaw Web

MediaClaw public-site reconstruction built with React and Vite. The project includes the observed public route catalog, Chinese and English navigation, product pages, blog pages, commercial/legal pages, and downloaded visual assets used by the frontend preview.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Scope

This repository contains the frontend reconstruction and its local evidence/assets. Account services, payments, plugin delivery, scraping backends, and Feishu writes are not connected; related controls are presented as frontend preview states.
